# lowdb 삭제 작업 노트

lowdb(JSON 파일 DB)를 모두 지우고 PostgreSQL(Prisma)만 쓰게 만드는 작업의 기록이다.
이 문서가 작업의 기준이다. 할 일을 찾고, 한 땀씩 작업하고, 기록하고, 작업 중 새 할 일을 발견하면 여기에 바로 적는다.

## 완료 기준

- `backend/`에 `./database`를 가져오는 코드가 0건이다.
- `backend/database.ts`, `data/*.json`, `lowdb`, `@types/lowdb`가 없다.
- 단위 테스트가 PostgreSQL 기준으로 모두 통과한다.
- 로그인, 가입, 거래 목록, 계좌 생성이 화면에서 동작한다. (사용자가 직접 확인)
- 샘플 데이터는 PostgreSQL에 넣지 않는다. (정해진 규칙)

완료 기준 확인 (2026-11-09): `database`를 가져오는 백엔드 코드 0건, 삭제 대상 파일과 패키지 없음, 단위 테스트 72개 통과, 타입 검사 통과. 화면 확인은 사용자 몫이다.

## 작업 방식 (땀수)

- 한 땀 = 엔티티 하나. 코드 전환, 단위 테스트 이식, lowdb의 해당 함수 삭제, 기록까지 끝내야 한 땀이다.
- 지우면서 간다. 마지막에 한꺼번에 지우지 않는다. `database.ts`가 매번 줄어드는 것이 진행 표시다.
- 작업 중 발견한 것은 바로 "발견" 표에 적고, 어느 땀 앞이나 뒤에 넣을지 정한다.
- 한 땀이 끝날 때마다 "작업 기록"에 적는다: 무엇을 했는지, 어떻게 확인했는지, 발견한 것.
- 규칙: 화면(UI) 코드는 바꾸지 않는다. 서버가 이전과 같은 모양으로 응답하게 맞춘다.
- 순서 규칙(D-10으로 바뀜): 먼저 PostgreSQL용 새 코드를 옆에 만들고 테스트로 확인한다(앱은 그대로). 모두 준비되면 한 번에 바꾸고(T-FLIP), 그다음 lowdb를 지운다.
